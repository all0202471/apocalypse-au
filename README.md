# 멸망 확장팩

SillyTavern 대화에 멸망 세계관을 더하는 AU 확장입니다. 재난을 조합하고 프롬프트를 편집해 나만의 세계관을 보관함에 저장할 수 있습니다.

**v1.0.0**

## 설치

1. SillyTavern의 **확장 → 확장 설치**를 엽니다.
2. 아래 저장소 주소를 입력합니다.

```text
https://github.com/all0202471/apocalypse-au
```

3. 설치 후 브라우저를 새로고침합니다.
4. 기존 채팅을 열고 입력창 옆 **마법봉 → 멸망 확장팩**을 누릅니다.

기존 사용자는 확장 관리에서 업데이트한 뒤 새로고침합니다. 새로고침은 새 업데이트를 불러올 때만 필요하며, 평소 설정 변경은 즉시 반영됩니다.

## 세계관 만들기

**확장 활성화**를 켜고 감염·문명·자연 중 원하는 유형을 누릅니다.

| 유형 | 재난 |
| --- | --- |
| 감염 | 좀비, 팬데믹, 기생충 |
| 문명 | 핵전쟁, 세계대전, EMP, AI 반란 |
| 자연 | 빙하기, 폭염, 대홍수, 가뭄 |

여러 재난을 동시에 선택할 수 있습니다. 다시 누르거나 선택 항목의 ×를 누르면 해제합니다. 신규 채팅은 재난 미선택, 확장의 최초 설치 상태는 OFF입니다.

**포스트 아포칼립스**는 멸망 이후의 삶을 중심으로 진행합니다.

## 프롬프트 편집

선택한 재난의 **프롬프트 편집**을 누르면 프롬프트가 열립니다. 입력하는 즉시 현재 채팅에 반영하며 자동 저장 요청을 보냅니다.

**기본값 복원**은 해당 재난만 복원합니다. 다른 재난이나 보관함 원본은 바뀌지 않습니다.

기본 AI 지침은 영어입니다. 사용자 입력은 공백과 줄바꿈까지 그대로 보존하며 HTML로 실행하거나 AI로 다시 작성하지 않습니다. 재난 사이 관계나 추가 배경도 원하는 개별 프롬프트에서 편집하면 됩니다.

## 보관함

보관함은 처음에 접혀 있습니다. **보관함**을 누르면 열리고 다시 누르면 접힙니다.

1. 세계관 이름을 입력하고 **현재 세계관 저장**을 누릅니다.
2. 드롭다운에서 저장한 세계관을 선택합니다.
3. **불러오기**를 누르면 현재 채팅에 적용합니다. 드롭다운 선택만으로는 적용되지 않습니다.

저장 대상은 선택한 재난, 각 프롬프트, 포스트 설정입니다. 재난 하나만 저장해도 되고 여러 개를 조합해도 됩니다. 저장 시점의 기본 프롬프트도 기록하여 향후 기본값 변경과 분리합니다.

불러오기는 현재 채팅의 세계관 전체를 교체합니다. 기존 수정이 있다면 확인창을 표시합니다. 불러온 뒤 편집하거나 보관함 원본을 덮어쓰기·삭제해도 다른 채팅에 이미 적용된 복사본은 바뀌지 않습니다.

## 활성화와 자동 저장

- 활성화는 **전역 설정**입니다. 마법봉 메뉴의 ON/OFF 배지에서 확인할 수 있습니다.
- 재난 선택, 포스트 설정과 수정 프롬프트는 **채팅마다 독립적**입니다.
- OFF는 주입만 끄며 선택·편집·보관함을 지우지 않습니다.
- 일반 설정에는 적용/저장 버튼이 없습니다. 변경 즉시 다음 응답 생성부터 반영됩니다.

데이터는 SillyTavern 사용자 설정과 채팅 메타데이터를 통해 서버에 저장합니다.

## 개발

런타임 외부 의존성이나 빌드 과정은 없습니다. 저장소 루트의 manifest.json과 JS/CSS를 그대로 설치합니다.

```text
manifest.json
index.js
core.js
defaults.js
presets.js
presets-ui.js
style.css
README.md
CHANGELOG.md
LICENSE
```

SillyTavern 1.19.0의 getContext, Popup, 저장·이벤트·프롬프트 API와 기본 팝업 스타일을 대조했습니다. 데이터 네임스페이스는 `apocalypse_au`, 주입 슬롯은 `apocalypse_au.world`입니다. 주입 위치는 IN_PROMPT(0), SYSTEM(0), World Info scan=false입니다.
